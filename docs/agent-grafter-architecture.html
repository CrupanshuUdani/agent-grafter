agent-grafter Architecture

Declared-pairs manifest → cross-platform materialization of AI-agent config & state

Declare, don't discover

  • • Manifest: source, copy[], link[], [targets.*]
  • • No scanning for agent installs, no guessed paths
  • • Targets are arbitrary labels — any harness works
  • • agent-grafter.toml lives in the dotfiles repo

Safety by construction

  • • remove() never deletes through a link into its target
  • • SymlinkProbe: real capability check, copy fallback
  • • NTFS junctions on Windows, symlinks on POSIX
  • • Scope-escape checks on symlinked path components

Reconcile & recover

  • • apply: plan (decide) then execute (write · prune)
  • • Clobbered files → .agrafter-backups/, keep last N
  • • doctor: read-only diagnostics, never writes
  • • winenv: elevation + Developer Mode facts (Windows)
